# Hikvision Домофон

Локально подключает IP-домофоны и внутренние панели Hikvision к Home Assistant. Облачный сервис Hik-Connect для основной работы не требуется.

Приложение принимает события устройства через Hikvision SDK и создаёт элементы Home Assistant через MQTT Discovery.

## Возможности

- состояние вызова и события звонка;
- события движения, вскрытия и состояния двери;
- открытие подключённых реле двери;
- ответ, отклонение и завершение вызова на поддерживаемых моделях;
- снимок при звонке и снимок по команде;
- перезагрузка устройства;
- управление подсветкой наружной панели;
- режимы охраны и сценарии внутренних панелей;
- произвольные безопасные запросы ISAPI.

## Перед установкой

- домофону рекомендуется назначить постоянный локальный IP-адрес;
- требуется MQTT-брокер, например официальное приложение Mosquitto Broker;
- используйте отдельную учётную запись Hikvision с минимально необходимыми правами, если модель это позволяет;
- не публикуйте порт Hikvision SDK `8000` в интернет.

Полная настройка описана на вкладке **Документация** или в файле [DOCS.md](DOCS.md).

## Поддерживаемые платформы

- amd64;
- aarch64.

Это защищённая сборка для личного репозитория: лишние разрешения Home Assistant удалены, секреты скрыты в интерфейсе и исключены из журналов.
